# IRONNOVA
نسخه به‌روزشده پروژه وب‌اپ ورزشی IRONNOVA.

## بخش‌های افزوده‌شده
- پنل مربی و شاگرد با اتصال Supabase (نیازمند اجرای SQL مهاجرت و تأیید مربی)
- بانک شروع غذاهای ایرانی و خوراکی‌ها با کالری تقریبی
- پخش فایل‌های صوتی انتخاب‌شده از حافظه گوشی
- فروشگاه نمونه و سبد خرید محلی (بدون پرداخت و سفارش آنلاین)
- دکمه آموزش حرکت در فهرست تمرین

## نصب و ساخت APK
ساخت APK از طریق GitHub Actions و workflow موجود در `.github/workflows/build-apk.yml` انجام می‌شود.

## راه‌اندازی پنل مربی
ابتدا SQLهای پایه‌ای که قبلاً در Supabase اجرا شده‌اند باید موجود باشند. سپس فایل `supabase/iron_coach_migration.sql` را در Supabase SQL Editor اجرا کنید. برای فعال‌کردن دعوت مربی، مدیر باید مقدار `coach_approved` حساب مربی را با UUID واقعی تأیید کند.

## محدودیت‌ها
- بانک غذا فهرست شروع است، نه فهرست کامل تمام خوراکی‌های ایران؛ کالری‌ها تخمینی‌اند.
- فروشگاه نمونه است و پرداخت، موجودی، ارسال و سفارش سمت سرور ندارد.
- موزیک‌پلیر فقط فایل‌هایی را پخش می‌کند که کاربر از گوشی انتخاب کند.
- اتصال مربی/شاگرد به ورود حساب، جداول پایه و SQL مهاجرت نیاز دارد.
- کد QR و اسکن دوربین در این نسخه پیاده‌سازی نشده؛ کد دعوت دستی وارد می‌شود.
