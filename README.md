IRONNOVA - بسته تکمیلی

این بسته بر اساس فایل فعلی مخزن ساخته شده و صفحه‌ها و داده‌های قبلی را حفظ می‌کند.

قابلیت‌های افزوده‌شده:
- پنل اولیه مربی/شاگرد متصل به RPCهای Supabase
- تولید کد دعوت و QR تصویری برای مربی؛ ورود دستی کد برای شاگرد
- انتشار برنامه و ثبت گزارش خواب/تغذیه/تمرین از طریق RPC
- بانک شروع غذاهای ایرانی، میوه، سبزی، لبنیات و پروتئین با مقادیر تخمینی
- پخش فایل‌های صوتی انتخاب‌شده از حافظه گوشی
- کاتالوگ نمونه فروشگاه و سبد خرید محلی

محدودیت‌های مهم:
- بانک غذا جامع و نهایی نیست و باید با داده معتبر تغذیه‌ای گسترش یابد.
- فروشگاه فعلاً نمونه و محلی است؛ پرداخت، موجودی، ارسال سفارش و پنل مدیریت سرور ندارد.
- موسیقی فقط فایل‌های شخصی/دارای مجوز کاربر را پخش می‌کند.
- QR برای نمایش کد دعوت ساخته می‌شود؛ اسکن دوربین داخل برنامه هنوز اضافه نشده و شاگرد کد را دستی وارد می‌کند.
- برای امنیت، حساب مربی تا تأیید مدیر نمی‌تواند دعوت صادر کند. ستون coach_approved به صورت پیش‌فرض false است.
- فایل supabase/iron_coach_migration.sql باید پس از SQLهای قبلی در Supabase اجرا شود.
- بعد از تأیید مربی، مدیر باید UUID حساب او را در دستور نمونه انتهای migration قرار دهد و آن دستور را جداگانه اجرا کند.
- قبل از انتشار عمومی، سیاست‌های امنیتی، حریم خصوصی، مجوزهای مربیان و عملکرد روی چند حساب آزمایش شوند.

ساخت APK:
فایل .github/workflows/build-apk.yml همان گردش کار قبلی را حفظ کرده است.
